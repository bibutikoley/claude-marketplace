Plugins

apple-notes

v0.1.0

MCP server giving Claude Code CRUD access to Apple Notes — Python + uv + the official mcp SDK, driving Notes.app through JXA. Notes.app is the source of truth, queried live on every call.

  • list_notes
  • get_note
  • create_note
  • update_note
  • append_note
  • delete_note
  • search_notes
  • list_folders
  • create_folder
  • delete_folder
  • health_check

Access scope

Restrict every tool to a folder allowlist with APPLE_NOTES_MCP_ALLOWED_FOLDERS (comma-separated names or full paths). Unset means unrestricted. Confirm the active scope any time with health_check. 

APPLE_NOTES_MCP_ALLOWED_FOLDERS="iCloud/Work,iCloud/Personal" claude

Requirements

  • macOS with Notes.app
  • uv installed (Python ≥ 3.12)
